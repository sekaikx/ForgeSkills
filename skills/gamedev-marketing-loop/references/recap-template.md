# Recap template

Load in Step 6. Bad news first: put the biggest miss at the top of the recap.

```
WORST NEWS  : <the biggest miss, in one sentence>
BEAT        : <name, date, channel>
COST        : <money> + <hours>
TARGET      : <count of the number>
ACTUAL      : <count>  (n = <visits/wishlists>, interval <..>) | insufficient data
ATTRIBUTION : high (tracked link) | medium (one event matches spike time) | low (events overlap) — <how>
OBSERVED    : <facts with source and date>
INFERRED    : <labelled reading>
KEEP/KILL   : keep | kill | one more try — fair try defined as <quote from channels.md>
NEXT        : <one action>
```
