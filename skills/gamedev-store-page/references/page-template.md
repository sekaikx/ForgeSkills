# Store page templates

Load while running Step 1 or Step 2. Fill every field from observation or mark "not observed".

## Teardown row

```
NAME + URL      :
DATE CHECKED    : YYYY-MM-DD
CAPSULE         : <what is shown> | readable text: <words>
SHORT DESC      : "<verbatim>"
SCREENSHOTS 1-3 : 1) <shows>  2) <shows>  3) <shows>
TRAILER 0-5s    : <what is on screen, is it gameplay: yes/no>
TAGS            : <as shown>
PRICE           : <shelf price> | not observed
REVIEWS         : <count, % positive> | not observed
```

## Page draft

```
CAPSULE BRIEF   : subject: <one> | readable word: <or none> | verb visible: <how>
SHORT DESC      : <verb> + <twist>, plain words, no adjectives that need proof
SCREENSHOTS     : 1 <core verb in play>  2 <...>  3 <...>  (all real gameplay; capture date)
TRAILER BEATS   : 0-3s <gameplay>  3-10s <verb loop>  10-30s <twist>  end <title, wishlist call>
TAGS            : <tag> (source: <competitor page(s)>), ...
```

## Measurement row

```
CHANNEL | UTM LINK | VISITS | WISHLISTS | CONVERSION (interval) | PERIOD
```

## Change log row

```
DATE | ELEMENT | OLD -> NEW | VISITS b/a | WISHLISTS b/a | INTERVAL | VERDICT
```
